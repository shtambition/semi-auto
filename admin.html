此页面需要后台口令

口令在服务启动时打印在终端，也保存在项目根目录的 .admin-token 文件里。 直接使用启动日志中带 ?token= 的后台直达链接可以免输入。

线上版为只读部署

当前站点是静态部署（Netlify / GitHub Pages），没有后端写入接口，所以不能在这里直接改配置。

  1. 打开仓库里的 semi-auto.json
  2. 点铅笔图标编辑，改完提交到 main 分支
  3. Netlify 会自动重新部署，约 30 秒后线上生效
在 GitHub 上编辑 semi-auto.json

想用带口令的后台编辑器：在本机项目目录运行 python server.py， 打开 http://127.0.0.1:8000/admin。

配置内容 · semi-auto.json

结构：product → 产品 → 分析类型 → 字段 → {"required": true/false, "type": "str"}。 字段可选扩展 options（枚举下拉）与 note（提示文案）。 保存后立即写入磁盘，公开页面 2 秒内自动刷新。
